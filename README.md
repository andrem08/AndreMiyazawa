## 🎯 Sobre

Este é meu site portfólio pessoal construído com tecnologias web modernas. Apresenta minha experiência profissional, habilidades técnicas e formação acadêmica. O site possui um tema de design glassmorphism com animações suaves e suporte bilíngue completo (Português/Inglês).

### Destaques Principais

- ✨ **Design Moderno** - Interface glassmorphism com tema escuro
- 🌐 **Bilíngue** - Suporte completo em Português e Inglês
- 📱 **Responsivo** - Otimizado para todos os dispositivos
- ⚡ **Performance** - Carregamento rápido e animações suaves
- 🎨 **Interativo** - Efeitos hover e conteúdo dinâmico

## 🚀 Instalação

### Pré-requisitos

- Um navegador web moderno (Chrome, Firefox, Safari, Edge)
- Editor de texto (VS Code recomendado)
- Git (opcional, para controle de versão)

### Configuração Local

1. **Clone o repositório**
   ```bash
   git clone https://github.com/andrem08/AndreMiyazawa.git
   cd AndreMiyazawa
   ```

2. **Abra no navegador**
   - Simplesmente abra `index.html` no seu navegador web
   - Ou use um servidor local:
   ```bash
   # Usando Python
   python -m http.server 8000
   
   # Usando Node.js (http-server)
   npx http-server
   ```

3. **Acesse localmente**
   - Abra `http://localhost:8000` no seu navegador

## 💻 Uso

### Navegação

- **Home** - Página inicial com visão geral
- **Sobre** - Background pessoal e biografia
- **Habilidades** - Habilidades técnicas por categoria
- **Experiência** - Histórico de trabalho detalhado e educação

### Alternância de Idioma

1. Clique no menu suspenso de idioma no cabeçalho
2. Selecione **BR** para Português ou **EN** para Inglês
3. O conteúdo é atualizado instantaneamente em todo o site

### Página de Experiência

- Clique no botão "Ver Experiências Completas"
- Navegue pelas experiências principais (Rede, Itaú, Inmetro, USP)
- Clique em "Mais Experiências" para funções adicionais
- Clique nos logos das empresas para efeitos hover
- Passe o mouse sobre os itens de ferramentas para animações

## 🎨 Personalização

### Alterando Cores

Edite as variáveis CSS em `css/modern-new.css`:

```css
:root {
  --primary: rgba(12, 11, 28, 1);      /* Background */
  --secondary: #231942;                 /* Background secundário */
  --accent: #7f5af0;                    /* Cor de destaque */
  --glass-bg: rgba(23, 18, 38, 0.92);  /* Efeito vidro */
  --text-light: #fff;                   /* Cor do texto */
}
```

### Adicionando Novas Habilidades

Edite `js/main.js` e adicione ao array de habilidades:

```javascript
skills: [
  {cat: 'Nome da Categoria', items: ['Habilidade 1', 'Habilidade 2', 'Habilidade 3']},
  // Adicione mais categorias
]
```

### Adicionando Experiência

1. Edite `experience.html` - Adicione novo item de experiência
2. Edite `js/experience.js` - Adicione traduções para ambos os idiomas
3. Atualize a função de renderização para incluir novos IDs
